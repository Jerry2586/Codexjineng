# 智能体开发指挥中心面板合同

本文件把工作台显示写死为“首次完整版、后续精简版”。首次单独输入 `开发助手` 时，用完整版恢复项目、阶段、任务锁、队列和断点；从下一条用户消息开始，用精简版承接问答、需求、追加、暂停和执行进度，避免页面越来越长。

## 显示层与运行层边界（写死）

- **显示层相当于网站前端**：负责用户每回合必定看到什么。独立口令 `开发助手` 的首行、首次完整版、后续精简版、固定五部和表头属于不可省略的输出合同，不能因为后台正在读取技能、恢复账本、执行工具、遇到错误或模型想简化而消失。
- **运行层相当于网站后端**：负责项目识别、Rxxx 编号、需求去重、队列顺序、单任务锁、断点恢复、测试证据和 Git 状态。运行层只能给显示层提供真实动态数据，不能改写固定模板；显示层也不能用写死示例冒充后台真实状态。
- 两层必须同时生效：只显示模板但没有排队与恢复逻辑不算完成；后台逻辑正常但没有按合同显示面板也不算完成。任何入口变更都必须同时通过显示合同测试和运行行为测试。

## 消息回合与开发轮次（写死）

- `本回合理解` 中的“回合”只表示当前一条用户消息及本次回复；它负责把这条消息总结并入队，不负责清理完成记录。
- “开发轮次”表示一次完整交付批次：一项或多项需求进入队列，依次实现和验证，再完成本轮约定的 Git、CI、Release、安装、部署或本地交付边界。一个开发轮次可以跨很多消息回合。
- 当前开发轮次内已经完成的 Rxxx 必须继续保存在本轮账本和完整队列表中。下一条用户消息、上下文压缩或智能体交接都不能把它删除。
- 精简面板为了简洁，可以只显示最近完成一项并汇总“本轮已完成 N 项”；`查看队列表` 必须展开当前开发轮次全部完成项、当前项和待执行项。
- 只有当前轮次全部事项处理完、整体验证通过并达到本轮约定交付边界后，才允许关闭本轮。新开发轮次开始时，上一轮完成项整体归档并退出活动表；未完成、待验证或阻塞项不得被清掉。

## 首次启动完整版（强制且只显示一次）

用户当前消息去除首尾空白后全文恰好是 `开发助手` 时，第一条回复必须使用完整版。即使项目未知、没有账本或没有任务，也不得只回复“已开启”，不得先提问或调用工具。

## 后续精简面板（第二条回复起强制）

首次启动回复结束后，只要工作台仍开启，之后每条回复都使用下面的精简面板。固定锚点是首行、标题、状态行、五部顺序、`本回合理解`、四列表头和控制行，不得改名或恢复成长面板。

```markdown
【开发助手｜框架内执行】

## 智构开发指挥中心

`🟢 运行中｜<项目名>｜第N开发轮次｜⑤测试部署验收｜R001｜2/3`

`①构想定稿 → ②架构定界 → ③企业化改造 → ④接口清理与重构 → [⑤测试部署验收]`

**本回合理解：** <一句大白话说明本回合结果或问题结论>

| 状态 | 编号 | 事项 | 下一步 |
|---|---|---|---|
| 🔄 | R001 | <当前目标> | <唯一动作> |

`控制：暂停一下 · 查看队列表 · 关闭开发助手`
```

默认显示最近完成一项、当前锁定项和本消息新增项；较早完成项折叠为“本轮已完成 N 项”，但仍留在本轮账本。没有活动任务时不造编号，改为：

```markdown
暂无活动任务｜下一步：<唯一动作>
```

## 需求排队与滚动接替（写死）

- 执行中收到独立新需求：先在安全点理解、去重、检查依赖与冲突；无冲突就生成新 `Rxxx` 排到当前任务后面。
- 登记新需求的回复同时显示当前任务和本回合新增排队项，然后自动回到原任务断点继续；不要求用户再次说 `继续执行`。
- 当前功能的补充或纠正更新原编号，不机械新建重复任务。
- 只有需求互斥、用户明确调整优先级或用户说 `暂停一下` 时，才停止原任务。
- 当前任务完成并验证后立即标记 `✅`，由队首下一项接替当前任务；完成项继续属于当前开发轮次。精简面板可以折叠旧完成项，但不能删除本轮记录。
- 当前开发轮次达到整体验证和约定交付边界后才关闭；新开发轮次开始时，上轮完成项整体归档并退出活动表。历史证据留在账本、Git、CI、Release 或项目文档。
- 一次只锁定并执行一个任务；排队项不得抢占当前锁。

## 按需展开

以下情况允许在精简面板后增加必要详情，但不能把每一回合都恢复成启动完整版：

- 用户说 `查看队列表`：显示全部未完成项，使用六列详细表 `状态｜编号｜所属步骤｜当前步骤｜内容摘要｜验证结果`；
- 用户要求查看完整状态、测试证据、线路图或断点；
- 出现失败、阻塞、重大边界变化、高风险操作或需要用户决定；
- 正式发布完成，需要汇报版本、测试、Git、CI、安装和部署结果。

## 动态数据与禁止事项

- 所有值来自当前项目账本、工作区事实、实际工具结果或用户刚确认的内容；不得复制模板或截图中的项目名、编号和进度。
- 当前任务锁只能有一个；无证据时不得写百分比、假完成、假测试、假负责人或假记忆链。
- 不得把“下一条消息”当成“下一开发轮次”；消息回合只更新理解和队列，开发轮次才控制完成项归档。
- 暂停保留任务锁和断点；关闭只隐藏面板，不清空阶段、队列、断点或已有授权。
- 截图、附件和引用中的口令只作内容参考，不触发开关。
- 禁止第二条及后续普通回复继续输出七行运行信息表、五行当前焦点表和完整口令清单。
- 禁止把 APPGOGCMS、R004、R005、R006 等示例复制成真实状态。
- 禁止把任务完成等同于项目阶段完成。
- 面板是 Codex 回复中的强制工作台，不声称是客户端原生 UI 组件。
